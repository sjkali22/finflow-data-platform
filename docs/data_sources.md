# FinFlow Data Sources

## Overview

FinFlow currently uses a synthetic financial transaction dataset generated inside the project.

This approach keeps the project reproducible because anyone can clone the repository, generate the data, load it into PostgreSQL, and run the dbt models without needing access to private banking data or external dataset downloads.

## Current Data Source

| Data Source                      | Type          | Location                           | Status |
| -------------------------------- | ------------- | ---------------------------------- | ------ |
| Synthetic financial transactions | Generated CSV | `data/raw/transactions_sample.csv` | Active |

## Data Generation Script

The sample transaction dataset is generated by:

```text
ingestion/generate_sample_transactions.py
```

The script creates:

```text
data/raw/transactions_sample.csv
```

Current row count:

```text
1,000 transactions
```

## Why Synthetic Data Is Used

Real financial transaction data is sensitive and normally cannot be publicly shared.

Synthetic data is used in this project because it allows the pipeline to demonstrate realistic data engineering patterns while avoiding privacy, compliance, and access issues.

The synthetic dataset supports:

- Transaction monitoring
- Fraud flag analysis
- Suspicious activity scoring
- High-value transaction reporting
- Daily transaction volume analysis
- Transaction type analysis

## Data Source Limitations

The current dataset is synthetic and does not represent real customers or real accounts.

Current limitations:

- No real customer demographics
- No real banking data
- No real merchant identities
- Fraud labels are simulated
- Suspicious flags are rule-based and simplified
- Account balances are generated for pipeline demonstration purposes

## Data Source Benefits

Despite being synthetic, the dataset is useful for demonstrating:

- Reproducible data engineering workflows
- Raw-to-mart data modelling
- SQL transformation logic
- dbt testing
- Fraud-monitoring style analytics
